# OntoMCDA

OntoMCDA é uma ontologia para representação de conhecimento no domínio de métodos multicritério de apoio à decisão (MCDA/MCDM), com foco na recomendação explicável de métodos a partir de premissas decisórias extraídas por PLN.

## Identificadores

- Namespace base: `https://doliveiracosta.github.io/ontomcda/onto#`
- IRI da ontologia: `https://doliveiracosta.github.io/ontomcda/onto#OntologyMCDA`
- Arquivo OWL: `https://doliveiracosta.github.io/ontomcda/onto/ontomcda.owl`
- Arquivo Turtle: `https://doliveiracosta.github.io/ontomcda/onto/ontomcda.ttl`

## Estrutura da versão publicada

- Classes OWL: 18
- Propriedades de objeto: 8
- Propriedades de dados: 2
- Indivíduos nomeados declarados: 159
- Triplas RDF: 1770

## Uso

A ontologia pode ser aberta no Protégé a partir do arquivo `onto/ontomcda.owl` ou carregada diretamente por ferramentas RDF/OWL a partir do endereço publicado no GitHub Pages.
